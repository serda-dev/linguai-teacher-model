## Review results

- Authority files retain original SHA-256s. Model selection is explicit original
  Qwen3-30B-A3B, not Qwen3.5 or a floating Ollama alias.
- Auth precedes request body/backend work. Exact system/user contract and model
  allowlist enforced; malformed/oversized requests fail without GPU generation.
- Render-once exact-token flow, output reserve and context-shift/fit disabled.
  One application generation gate, one engine slot, no inference retry.
- Schema-constrained generation is independently revalidated for schema, exact ID,
  no truncation and EOS; no label repair, routing or provenance insertion.
- Non-labeling probes; lifecycle/timeout errors are redacted. No document writes,
  DB clients, corpus fetching or logging of raw requests/completions.
- Backend loopback only; direct TLS supported; secrets excluded from build context.
  Raw HTTP is only for local/private encrypted-tunnel paths documented in runbook.
- Body transfer is bounded by a 3-second socket shutdown timer in Gunicorn;
  backend preparation/generation share an 18-second deadline starting before body
  read. A disconnect can leave bounded work until cancellation/deadline.
- Gunicorn 26.2.2 selected from the current official release; its actual process
  startup/TLS handling remains in the Docker gate, not claimed by WSGI mocks.

Disposition: code/test/docs candidate is reviewable and suitable to build for a
controlled deployment test. **Not yet production/GPU accepted.** No confirmed
unresolved source bug found in this pass; the open evidence gates above remain.
